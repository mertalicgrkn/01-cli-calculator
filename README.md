# PROJECT NAME & SHORT DESCRIPTON
The project is named 01-cli-calculator, and it is a calculation tool that allows performing the modulo operation in addition to the four basic arithmetic operations.

## Features:
- '+' -> Adds the 2 numbers entered by the user.
- '-' -> Subtracts the 2 numbers entered by the user.
- '*' -> Multiplies the 2 numbers entered by the user.
- '/' -> Divides the 2 numbers entered by the user. (Division by 0 results in an error.)
- '%' -> Calculates the modulo of the 1st number with respect to the 2nd number entered by the user. (Division by 0 results in an error.)

# How to Run
Once you compile the code via your IDE, the program will run if you enter the inputs sequentially (First Number, Second Number, Operator).
